# Student Affairs Office (SAO) Management System
### Cebu Technological University - Argao Campus
** Project Completed:** May 2024

A web-based management system built with **Django (Python)** designed to digitize operations for the Student Affairs Office.

##  Context & Contribution
This project was developed as a collaborative academic requirement in **May 2024**.

**Please Note:** This repository is a portfolio showcase of **my specific contribution: The Alumni Module.**

While the sidebar navigation displays the full architecture of the intended system (Student Life, Scholarship, Medical, etc.), **only the "Alumni" module is fully functional in this demonstration**, as other modules were handled by teammates during the project period.

* **My Role:** Full Stack Developer for the Alumni Module
* **Status:** Archived / Completed (May 2024)

##  Key Features (Alumni Module)
I designed and implemented the full logic for the Alumni ecosystem, including:

* **Alumni ID Request System:** Allows alumni to search their records and request IDs.
* **Graduate Tracer:** Tracks employment status and data of graduates.
* **Event Management:** Handling Alumni Reunions, Events, and Job Fairs.
* **Digital Yearbook:** A digital archive of graduates.
* **Admin Reporting:** Generating transaction reports for ID requests and events.

##  Tech Stack
* **Backend:** Python, Django Framework
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite (Development) / MySQL (Production capable)
